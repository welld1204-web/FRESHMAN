# NOTES — our own chapter notes

One folder per chapter, named after the 7 chapters of the official MoSHE
Phys 1011 (Freshman General Physics) module.

How we use it: open a chapter's `Notes.md` and write your notes topic by
topic, one commit at a time. The official module PDF and the syllabus are
in the RESOURCE folder if you need to check the chapter content.
